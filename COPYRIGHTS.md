# Copyright, trademarks, and software sources

This project is designed to avoid bundling artwork or binaries from third parties in its GitHub source files.

- `proxy-os-neon.svg` is original geometric artwork made for this project. The reference image supplied in chat is not included or redistributed.
- No Ubuntu, Firefox, Opera, Steam, Heroic, Lutris, or Bottles logo is included.
- The build script downloads software from Flathub and Ubuntu repositories during the build; it does not store those packages in this source repository. Each package remains subject to its own license and trademark terms.
- “Firefox” and “Opera GX” are used only as plain text to identify the software. Mozilla's distribution policy places conditions on distributing Firefox branded binaries; Opera GX is proprietary software from Opera.
- Ubuntu and Canonical names/marks are owned by Canonical. Proxy OS is an independent personal customization and is not endorsed by Canonical.

## Sharing

Keep the GitHub repository to the original SVG, scripts, and documentation. Do not commit Ubuntu ISO files, Flatpak bundles, vendor packages, proprietary logos, or a generated ISO. Canonical's policy says modified Ubuntu images associated with Ubuntu trademarks require approval/certification or removal/replacement of those marks and other steps. This project does not remove all Ubuntu branding from the upstream ISO, so the safe scope here is personal use and testing. Obtain appropriate review and permissions before publicly distributing a modified image.

This is a practical source and attribution note, not a legal opinion or a guarantee that a particular distribution complies with every license. Check notices and terms for the exact software versions included in any image you make.
